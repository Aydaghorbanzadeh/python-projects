
# Wallet Manager

A simple wallet management system written in Python.

## Features

- Show current balance
- Deposit money
- Withdraw money
- Check available balance
- Menu-based interface

## Technologies

- Python

## How to Run

1. Make sure Python is installed.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```

## Description

This project allows users to manage a simple wallet by checking their balance, depositing money, and withdrawing money.
